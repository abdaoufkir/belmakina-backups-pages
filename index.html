BeLmakina Backups
Internal operational utility

Secure backup storage for BeLmakina POS

BeLmakina Backups is an internal tool used by the BeLmakina shop operator to preserve recoverable copies of the BeLmakina point-of-sale (POS) system's database and product-image storage.

What the application does: The tool prepares database and storage backup archives, encrypts backup content, and uploads backup files to a dedicated folder in the operator's Google Drive account. It helps the operator recover business records after an incident.

Why Google Drive access is requested

The application uses the Google Drive API with the limited drive.file permission to create and manage backup files and folders that the application itself creates. It does not request general access to unrelated personal Drive files.

Who uses it?

This is a private, operator-managed backup workflow for a single shop. These pages are informational only; they do not expose POS data, backup files, login details, or administrative tools.
